# MERN

This repository contains my daily tasks for the 60-day MERN Stack 

## Day 1
**What I learned:**
- What MERN stack is (MongoDB, Express.js, React.js, Node.js)
- Difference between frontend and backend
- What npm is and how to use it
- Basics of Git and GitHub

**What I built:**
- A basic Node.js project with Express server (`day1/backend`)
- A basic React app with a heading, text, and button (`day1/frontend`)

**How to run:**
- Backend: `cd day1/backend && node server.js`
- Frontend: `cd day1/frontend && npm start`
